# 个人信息保护影响评估报告（PIA · 草案 v0.1）

> 法源：《个人信息保护法》第 55、56 条。触发情形（本项目占三）：处理敏感个人信息
> （不满十四周岁未成年人的个人信息属敏感信息）；利用个人信息进行自动化决策（支架档位
> 建议）；向第三方提供个人信息（AI 服务、研究方）。
> 状态：**草案**。结论栏留空待评估会议签署；技术事实锚定 2026-08-18 提交 50a9de5。

## 1. 处理活动概述

K-12 结对编程教学平台：学生浏览器 IDE + AI 教学助理 + 教师控制台 + 研究数据导出。
数据清单以 `store_erasure.ERASURE_MAP`（24 类，测试强制与数据库同步）为准——
本报告不另行维护清单，防止两处漂移。

## 2. 合法性·正当性·必要性分析

| 处理活动 | 必要性论证 | 最小化措施（已实现） |
|---|---|---|
| 行为事件采集 | 过程性评价是课题的研究对象本身 | 求助话语只存**前 40 字**且先脱敏；聊天正文零采集 |
| AI 交互 | 教学干预（导师式辅导）| 送出前本地脱敏；回复原文不落库只存分类；未同意者 403 |
| 档位自动建议 | 因材施教 | **建议不自动执行**，教师确认制；建议不读六维分（防自反循环，有静态断言测试钉死） |
| 研究导出 | 论文与效果评估 | 假名化 + 剔除自由文本 + 相对时间；未同意者默认剔除 |
| 时长统计 | 防沉迷法定义务 | 服务端计时防伪造；只计总量不记内容 |

| # | 风险 | 可能性 | 影响 | 已有缓解 | 残余风险处置 |

## 4. 安全措施对照（技术侧已验证项）

- 代码执行：容器沙箱（--network none / read-only / cap-drop ALL……详见沙箱红队报告）
- 提示注入与越权：护栏红队报告 + 常驻回归语料
- 权限：JWT 角色门禁；学生仅读自己；教师班级范围；删除仅教师执行且留审计
- 删除完整性：登记表由测试扫描 sqlite_master 强制全覆盖（新表未登记即测试红）
- 外键陷阱已封堵：SQLite 外键默认关闭，级联删除不可依赖——已显式子查询删除并有专测
