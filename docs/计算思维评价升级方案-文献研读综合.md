## 一、5 断层对 CX 的真实成立度（重判）

| 断层 | 综合诊断 | 对 CX 是否成立 | 真实状态 |
|---|---|---|---|

| **2 评价无CT** | 六维分是行为启发式非构念 | ⚠️ **半真** | neutral 已拆自反污染（本 session）；但根子仍在：六维仍是 f(行为)，**没有任何外部测量证明它测的是 CT** |

| **4 无信效度机制** | 无 Kappa/α/金标准 | ⚠️ **半真** | 报了 α + Cohen's d；但**① 对 Bebras 报 α 是统计范畴误用**（见下）；② 无双编码 Kappa、无外部 CTS 效标、无 AI 评分金标准 |
| **5 证据链断裂** | 行为→六维→"CT水平"无锚、无法证伪 | ✅ **真·病根** | CX 有硬生成的边界声明（本 session），但**没有一个独立外部证据源能反驳六维**——所以永远自证、测不出自己错在哪 |

**病根一句话**（综合原话，对 CX 成立）：平台的病不是"维度切错"，而是**评价链从头到尾没跨过"行为→构念"那一跳，且没有任何外部锚把这一跳钉住**——这使 mean/sd/Cohen's d 给了假精度。

**一个 CX 真实的 bug（综合正确识别）**：`study.py` 的 `_alpha` 对 18 题 Bebras 式**能力测验**报 Cronbach α。α 是**态度量表/同质构念**的信度量；Bebras 是抽样型/形成型能力测验，条目蓄意跨难度跨维度，**低 α 是好设计不是缺陷**。对它报 α 是范畴误用，应改报**平行卷/重测信度 + 逐题难度 p / 区分度（点二列相关）**。

## 二、维度体系的抉择：六维 vs 四要素

**结论：以用户已文献验证的 CT 四要素为主报维度（问题分解 / 抽象建模 / 算法设计 / 调试评估），把 CX 六维折叠映射进去。** 依据：01 汤倩雯（借 CTS）、06 吴晓彤（照搬 Barnard）、04 石斯瑾（每维一条文献锚）三篇共同证明——**维度效度来自外部可引用框架，不是自定义公式**；而四要素可上溯 Wing / CSTA / Brennan&Resnick，是三套里唯一有外部背书且用户已验证的。

> ⚠️【三波订正】01 汤倩雯全文「效度/Cronbach/KMO/因子分析/前测」0 次命中，从未做过任何量表验证，不能作"维度挂靠效度来源"的正面例证——它是"引用+删改+零自证"的反例（详见第三波总审§二·01汤倩雯节）。

| CX 六维 | 折叠去向 | 依据 |
|---|---|---|
| decompose | → **问题分解** | 有 fix/switch 行为锚 |
| abstract + model | → **抽象建模**（合并） | 埋点层两者大概率高相关到同一因子；model 无独立可观测动作 |
| algorithm | → **算法设计** | 有 run/success 锚 |
| verify | → **调试评估** | 有 error/fix 锚 |
| transfer | → **降级为延迟测** | 单次结对 session 内无任何行为能证明迁移；只能在"前测→延迟后测"层面测，**不要在实时看板给迁移等第** |

**每维必配机器可读的效度 manifest**（抄 04 每子维一条文献锚 + 07 动作即定义）：`理论/课标引证 + 可观测操作定义(哪些 ct_event 算证据) + 映射四要素 + 证据源类型(行为代理|作品|卷子) + status(core|exploratory)`。**找不到独立证据源的维度，报告端输出"数据不足/暂不出等第"，而非硬给等第。**

> 诚实标注：四要素能否在结对行为数据上**经验地区分成 4 个因子**，需真实数据做验证性检验。拿到数据前，四要素是"理论上可辩护的报告结构"，不是"已验证的因子结构"。若数据显示抽象建模与算法设计塌成一维，退到 3 维，让数据裁决。

## 四、升级路线（重锚 CX，因研究层已存在而更轻）

> 排序原则：**先补"能说自己错了"的证伪机制（外部效标 r + 拆自反污染 + 证据可回溯），再补作品测评与语义编码，最后 LSA/信效度看板**。在拿到"六维分↔外部 CTS 分"那个相关系数之前，其余精细化都是在放大未验证的测量。

### P0（止血 + 第一次拥有外部锚）— 因 studies 已存在，主要是"接锚+纠范畴误用"
1. **外部效标题块接入**：`seed_ct_v1.py` 支持在前后测嵌入一份 CTS/CTt 效标题块（与 18 题并行），题目预打标到 CT 四要素。
2. **效标关联效度**：`study.py` 报告端新增——join 每生六维行为分 × 外部 CTS 对应侧面分，返回 Pearson/Spearman r + n + p + 95%CI，**并入对比报告，敢报低 r**。这是六维第一次从"断言"变"可证伪假设"。
3. **纠 α 范畴误用**：`_alpha` 对 Bebras 卷停报 Cronbach α，改报逐题难度 p + 区分度（点二列相关）+（有等值卷后）平行卷信度。
4. **维度 manifest + 6→4 折叠**：`ct.py` 旁新增 `ct_dimension_anchor.yaml`（每维文献锚/操作定义/映射四要素/证据源/status），报告端按四要素聚合；找不到证据源的维度出"数据不足"。
5. **v1_all 也拆或标注自反污染**（neutral 已拆）。

**验收**：报告页出现"六维分↔外部 CTS 分"相关系数（哪怕 r 低）；Bebras 卷不再报 α 改报难度/区分度；每维等第可下钻到 evidence+confidence。
**投入**：后端 ~1.5 周（比综合估的 2 周少，因 studies 已在）；教研 ~3 天（18 题打标四要素 + 接一份 CTS/Bebras 效标题块）。**动六维公式=bump FORMULA_VERSION，跨版本数据不可比，须谨慎。**

### P1（补构念）— 作品测评 + 语义编码
1. **作品检查点**：新表 `artifact_checkpoint`（study_id/user_id/role_at_capture/code_snapshot/rubric_scores/scorer_type）；触发复用 `design_create` + 提交成功；Python `ast` 自动结构评分；`ai.py` navigator 注入 artifact-probing。
2. **语义编码层**：新表 `dialogue_codes`（message_id/角色/码/coder/confidence）；**护栏：人工双编码 Kappa≥0.8 金标准种子集，AI 编码器达标后其分才进聚合**。
3. **结对语料先开放编码补"协作协调"类目 + 按角色归一化**（Murphy 框架在"生-生+AI"三方语料不能直接照搬，driver 天然多创造 C、observer 天然多评价 E）。〔03〕

**投入**：后端 ~3 周；**教研标注冲刺是瓶颈**（2 编码员标到 Kappa≥0.8 约 1–2 周，最贵最不可省）。

### P2（结构化证据 + 守门）— LSA + 信效度看板 + fail-closed
1. **LSA 路径分析**：`lsa.py` 纯 Python（Sackett 转换频次 + 调整残差 Z>1.96），数据源=`dialogue_codes` 编码序列，前端画思维闭环图；**按 role 分层或以 pair 为分析单位**（结对是双人交织，塌成一条链会造出不存在的循环）。〔07〕

## 六、诚实边界（哪些无法照搬 / 需真实数据 / 方法学底线）

**初中结对编程场景无法照搬的**：
- **Murphy R/U/A/E/C 编码框架**在"师-生-AI"验证，CX 是"生-生(driver/observer)+AI"三方；大量话语是协作协调（"你先跑""换我开"），且 driver/observer 话语功能天然不同——直接搬会构念污染，必须先开放编码补类目 + 按角色归一化。〔03〕
- **一阶马尔可夫/LSA** 默认单人序列，结对是双人交织；塌成一条链会造出不存在的循环，须按 role 分层或以 pair 为单位。〔07〕
- **Cronbach α** 对 Bebras 是范畴误用；**KMO/因子分析**在一个班几十人样本下做不出稳健结构，别为凑效度硬做。〔06/08〕
  > ⚠️【三波订正】结论仍成立，但引证需与 06、08 解绑（06/08 全文无 Bebras/CTt 命中，凭空归属，详见第三波总审§二·06吴晓彤／08王玉雯节）。
- **transfer 维**单次 session 内几乎无可观测证据，只能"前测→延迟后测"测。

**必须真实数据才能定的（现在不能拍板）**：
- 四要素能否在结对行为数据上区分成 4 个独立因子——需首轮数据验证性检验；塌成一维就退 3 维。
- **"六维分↔外部 CTS 分"的相关系数到底多高——这是整个方案的成败点，只有跑完一轮 pretest→posttest 才知道**。方案能保证的是"把 r 算出来并公开"，不能保证 r 好看。**若 r 很低，正确动作是承认"六维测的是活跃度不是 CT"并重切，而非掩盖**——这是 CX 超越 8 篇文献（尤其梁家健第75页那句永远做不到的自供）的唯一诚实之处。
- AI 编码器能否达 Kappa≥0.8——需先有金标准种子集；达不到就长期靠人工，成本模型重估。
- 六维魔数（系数、常数、饱和 k 值）的替代权重——需真实语料标定，现给的是结构不是最终参数。

**方法学底线（写进研究层设计规范）**：
- "有前测/有流程"≠有效度（01："引用即效度不成立"）。
- "两个显著结果并置"≠因果链，跨环推断要做中介/ANCOVA（02/06）。
- 对照基线绝不设成"同一任务第一次尝试"（07 伪对照）或"上学期期末分"（08 张冠李戴）。
- 三主体若三条腿都主观且同源（AI 评/自评都从同一份行为日志导出）是**伪三角**；至少一条腿必须是方法独立的盲评客观锚。〔04/08〕
