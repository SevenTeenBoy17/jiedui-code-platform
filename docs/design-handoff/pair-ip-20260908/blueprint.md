## 同页浮层蓝图

1. 在形象上方打开一个短窗口，不切换路由、不替换当前工作区。
2. 第一层仅展示角色选择、一句职责与三个行动入口；以文字与选中态共同表达当前角色。
3. 学生主动选择后获得对应引导，再回到任务。辅助解释按需展开，不依靠更多统计卡片或长段落。
4. 研究测评只提供流程与操作帮助。教师控制、未发布答案与独立作答条件不随 IP 切换而变化。
5. 实现验收需检查短屏内部滚动、窄屏可用、Escape、关闭焦点回归、键盘角色切换和 reduced-motion。画布示意本身不证明生产组件已满足这些要求。
