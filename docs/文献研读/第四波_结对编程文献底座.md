4. **作者名转写风险一处**：ERIC 对 #9 的抓取把第二作者转写为 "Denning"，已按同团队多方来源校正为 Denner；精读时核对。凡标「作者待核」的条目（11 处）同理。

6. **预印本未同行评审**：#44/#46/#47/#48/#50（arXiv）。#47 对平台架构支撑最强却是预印本——引用时标注，并跟踪其正式发表。
