## 三、两波结论的矛盾与调和

以下11条按「会不会在答辩现场爆炸」排序。前四条是承重级冲突。

### 3.1 主结局之争（最会爆炸）

- **第二波**：主结局应预注册为过程性指标（CT事件密度、路径节点数、调试收敛速度、独立性指数、支架渐退曲线），作品质量作次要结局（依据：方海光62人实验里知识测试p=.128、任务完成度p=.351不显著，而过程类素养显著）。
- **第一波**：埋点→六维「不是待检验的经验推断，是算术」；「六维分→计算思维水平是同义反复冒充推断」；DV=干预物的输出即梁家健式循环。

**调和（按「回答的问题不同」分层，两波都不撤回）**：
- **主结局 = 外部效标后测 + 盲评作品分**，回答「能力是否变化」。
- **过程性指标 = 操纵检验 / 干预保真度指标 / 中介变量**，回答「干预是否按设计发生了、通过什么路径」。
- 论文写法固定为两句：过程指标证明「三轮渐退真的发生了」，效标证明「CT真的动了」；二者之间**必须做中介检验而非并置**。预注册文件显式写明：过程指标不作为成效主张的依据。

### 3.2 CT四要素定位：轴不冲突，接口口径互斥

- 第一波谈的是**测量/报告维度**（六维折叠为四要素、abstract+model合并、transfer降级）；第二波谈的是**时间结构划分轴**（轮次改按制品完成度R1能跑/R2跑对/R3跑好，CT要素降为每轮重心标注）。**两者正交，可共存**——第二波的改法反而帮了第一波：轮次不再绑CT要素，四要素才能在每轮完整走一遍，才有可能在三个时点重复测量同一组维度。
- **真正冲突在字段口径**：第一波要6→4折叠、键名对齐四要素；第二波全篇以「ct.py六维」为契约（learner_state.mastery_snapshot、四职能契约表、任务链取数），且 idea 20 还要新增第七维「人机协同」。

**调和**：
1. 文档写死：CT四要素是**报告与测量层**维度，制品完成度是**时间结构层**划分轴，二者不同轴不互斥（这一句直接回答审稿人「为什么轮次不按CT要素切还叫CT导向」）。
2. 接口改版本化对象 `ct_profile{version:'v3', internal_dims[6], report_dims[4], evidence_refs}`：内部保留六维作证据分组，对师/对生/对论文一律只出四要素。
3. **「人机协同维」不得进CT画像**——它是干预保真度指标，混进能力维度就是自反污染换名复发；单独放 `fidelity_metrics`。

### 3.3 作品测评 vs 输出契约：支架档位系统性污染客观锚

- 第一波把作品rubric分定为三角互证里那条**盲评的客观锚**（三facet：功能性/创新性/结构优化 + Python ast结构静态分析）。
- 第二波让支架档位在学生间与轮次间系统性不同：R1只要求「能跑」，example档给**同构异题的完整可运行示例**，idea 26 还规定优先从题库取现成同构题。

**后果**：低档位学生拿到近乎可直接改写的完整示例，其R1作品在「功能性」上必然高分；ast结构分只看最终代码、看不见来源。**作品分测到的主要成分是「你被给了多少示例」，不是CT**；它当不了锚，反而把支架配置差异误读成能力差异，并反噬第二波（作品分虚高触发错误的档位下调）。

**调和**：
1. 日常作品分**必须分档位报告**，`scaffold_level` 作协变量入模，绝不跨档位直接比较。
2. **真正的客观锚改用第二波 idea 17 的无支架检查点（silent probe）产物**——它天然满足「方法独立+盲评」，又是第二波论证渐退可测性的唯一手段，**是两波唯一天然重合的锚点**。
3. 第一波的 artifact rubric 与 artifact-probing 追问脚本整体迁到 silent probe 产物上执行；日常提交只留 ast 客观子项做形成性反馈。这一条同时省掉一整套评分流程。

### 3.4 P0优先级：两个P0抢同一人力，且存在真实循环依赖

- 第一波：「在拿到六维分↔效标那个相关系数之前，其余一切精细化都是在放大未验证的测量」，P0=studies+criterion-validity端点。
- 第二波：「必须先做 learner_state 持久层与 round 维度，其余三个缺口全部挂在它们上面——本次综述最重要的工程排序结论」。
- **循环**：(a) r 只有跑完一轮真实 pretest→posttest 才有值，而若那一轮跑的还是没有 learner_state/round 的旧CX，测的就不是待验证的干预，换干预后 r 要重算；(b) 反过来，scaffold_policy 的 floor 若读 ct 分，就是用未验证的测量驱动真实教学干预。

**调和（拆三段 + 一条硬约束切断循环，不再争先后）**：
- **P0-0（硬截止、成本最低、必须在首轮开课前完成）**：前测卷嵌入效标题块 + 18题打标四要素 + `ct_criterion` 建表（教研3天+后端2天）。**错过开课日就永久无法回溯补前测**（08「用上学期期末分当基线」的教训不可逆）。
- **P0-a（主工程量）**：learner_state + learning_round + ct_events.round_index，让首轮跑的就是待验证的干预。
- **硬约束（解循环的关键）**：**scaffold_policy v1 禁止读 ct 六维分**，只读原始可观测信号（连续运行失败次数、无代码增量、同类错误重复率），即第二波自己定的「只采信有动作的失败」纪律；等效标 r 达阈后才允许把 CT 分接进 floor。
- **P0-b（可后置）**：criterion-validity 端点——它是分析代码不是前置基础设施，首轮数据落库后再写。

### 3.5 迁移（transfer）：禁令 vs 出口判据

第一波两处明令 transfer 降级为探索性/延迟测、「不要在实时看板给迁移等第」；第二波把 R3 出口判据定为「自查表勾选 + 一道迁移题」，且该达标位要进 exit_criteria、round_transition 与轮次报告——事实上成了课时级迁移等第。

**调和：拆词，避免同词异指。** R3 的迁移题定位为**教学出口任务**，字段 `r3_exit_task_passed`，只记 pass/fail 与用时，不进CT画像不出等第，报告措辞用「完成迁移任务」；迁移作为**能力维度**只在延迟后测（课程结束后3–4周）报告。R3 名称可保留，但图注与正文各加一句显式辨析。

### 3.6 独立性指数：自反污染原样复发，且超出原文授权

idea 18「独立性指数 = 1 − AI生成占比（LCS+粘贴时间邻近度）」写进 learner_state、列为R3结业门槛、进主结局候选。但第二波自己的输出契约把代码围栏设为 stop sequence、diagnose档禁任何代码块——**AI输出里根本不含代码，LCS结构性趋近0，指数在中高档位恒等于1**。它测的是闸门是否生效，不是学生是否独立；**档位越高分越高，方向与「能力越强档位越低」相反**。另：方海光原文的「作答独立性」是**任课教师人工评分**的四维之一，机器化改写超出原文可背书范围。

**调和**：改名 `gate_effectiveness`（干预保真度），只在example档与R1有解释力，不作结业门槛、不进主结局、不进CT画像。学生独立性改用第一波的证据链口径：**「排除外源片段后仍带完整调试轨迹（error→fix链）的代码占比」**——不依赖AI输出内容，因而不随档位漂移。R3结业门槛改用无支架检查点通过率。

### 3.7 AI语义编码成本：两波判断相反，唯一实证站第一波这边

第一波要求「AI-人Kappa达标前语义分在聚合中置零」（贵）；第二波 idea 16 写成「SSE后异步轻量分类」（廉价）。15孙贞岳的实证：基座裸用仅31%/35%，94%靠「人工标注10节SFT + 30节RAG + 前后各5句未来上下文 + 全程课后离线 + 专家人工校验」。**CX从Anthropic兼容代理流式，无自训练能力，做不了SFT；实时也拿不到"后5句"。**

**调和**：实时打标只能低置信度、仅作支架决策的近似输入（允许错、可回滚），标签保留 `provisional/confirmed` 两态；报告级CT分走离线批处理+人工校验位。**明令不可写「参考孙贞岳94%」。**

### 3.8 AI评分权限：口径相反

第一波「三主体各打一次：AI评/师评/自评」；第二波主张职能改名「评价支持/证据组织」，判定权在教师。若论文同时出现「AI打作品等第」与「判定权在教师」，是一眼可抓的自相矛盾。

**调和：按rubric子项切权限。** AI只出**客观子项**（ast结构分、用例通过率、调试轨迹完整度）与**归因候选**；**主观子项与最终等第**由教师确认，AI输出在教师界面一律标「候选」。职能名采用「评价支持」。第一波的Kappa闸保留但换对象——测「AI归因候选 vs 教师最终归因」的一致性。

### 3.9 作品归属：片段级 vs 作品级

第一波「checkpoint绑定当时driver」得到**片段级**归属，第二波「每轮≥1次互换、共6个驾驶段」使一份R2作品的driver至少切换过一次，而rubric是**作品级**评分。

**调和：两级归属。** 作品级rubric打给pair（共同分）；个人分由两段构成——该生driver段内的code diff（用 collab.py 已有的服务端权威 role_switch 时间轴切段）+ 该生observer段内被采纳的chat建议（chat文本与随后diff的时间邻近+内容匹配）。后者恰是第二波说的「CX独有的动机标注源」，不额外加成本。「自评」改为「各自陈述自己那段的设计依据」，正好接上 artifact-probing 脚本。

### 3.10 第二波内部自相矛盾：效率指标

§7.1 立了硬口径「不可抄谢鑫的效率指标，抄了等于承认效率是教学目标，自拆CT导向的台」，§7.3-6 却把「调试收敛速度」列入预注册主结局；而第一波的「调试评估」维锚本就是 error/fix 计数。**收敛速度与「开发时长缩短」在测量层是同一类量。**

**调和**：给「调试收敛」重下**诊断性**操作定义——是否基于报错信息定位、是否形成「假设→最小改动→验证」的成对事件、同类错误是否复发（测修改的质量而非次数与时长）；或明确标注为过程性描述指标、不进主结局。二选一并写进指标手册。

### 3.11 第一波锚错代码库（事实前提级误判）

## 八、诚实边界：三波之后仍然不知道的

以下每一条都**必须靠真实数据或人工判断解决，不能靠再读文献解决**。它们同时是论文「研究局限」一节的候选内容。

**测量层**
1. **效标 r 的真实值未知，且可能很低。** 若 r 低，四要素画像只能定位为"过程性形成评价"，不能作能力断言——**必须敢报低 r**，把它写成发现而非失败。
2. **四要素能否在数据上区分为4个因子未知。** 单班N=15–20对做不出稳健结构；抽象建模与算法设计可能塌成一维（第一波已承认应退到3维、让数据裁决）。
3. **自编18题的难度p与区分度全部未知**，18题是否足以覆盖四要素、每要素几题才够，尚无实测。
4. **silent probe 是否会被学生当"考试"而改变行为**（霍桑/评价焦虑）未知；它同时是主要客观锚，一旦被污染没有备份锚。
5. **支架档位对作品分的污染幅度未知**——须在 scaffold_level 作协变量后看残差才能知道日常作品分还剩多少信息量。

**干预层**
6. **三轮渐退能否在真实课时里排开**（1节/周 vs 需3课时跨3周）未知；**45分钟内降三级学生是否感知得到**未知，若感知不到则渐退是走过场。
7. **hops 是否真的会随时间下降**未知；若不下降，goal_anchor 机制只解决了"navigator无正向目标"，没解决"渐退无度量"。
8. **降档是否有污名化效应**未知（第二波自承需访谈证据）；弱生长期停在 example 档是否形成能力标签固化，无一篇文献做过分层效应分析。
9. **结对是否会被AI挤占**（observer 遇疑先问AI而非问driver）未知——**这是第二波三个原创点共同的未检验前提**，只能靠T1-12的新指标实测。
10. **教师采纳率未知，可能<10%**；且若执教者是研究者本人，这个数字毫无外部效度。
