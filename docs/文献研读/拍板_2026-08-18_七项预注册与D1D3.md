## Q1 · U4 锚点：**不含 asks=0 的回复**
纯鼓励/陈述型回复后的代码变更多为进行中的编辑而非对支架的承接——配进去把巧合编辑算成
命中（U4 偏高=自利=非法方向）。与 U1 共用分母概念，两量可直接对读。落点：field_notes.u4。

## Q2 · 首版「对空 diff」：**不进 rate，first_version_jump_n 披露计数**
新建作品直接粘贴是最典型的整段卸载，但首版无基线、可能是模板+正常起步。进 rate 的
风险方向自利（非法），全丢又把最强信号弃了。折中：披露计数+留人工复核，预注册规则
（no_baseline 单列）不动。落点：u5.first_version_jump_n。

## Q3 · 登记键：**not_computed → metric_registry，schema jiedui-uptake/v1 → v2**
键名与内容相反（not_computed:{computed:true}）写进论文附录是永久自我矛盾。平台尚无
外部消费方（真实数据 0 行）——这是把形状改对的最便宜时刻。

## Q4 · run() **await autoSave()**（维持 142068f 的选择）
U5「立即 run 含同秒」的判据前提是版本先落——await 使它由统计性成立变构造保证。
代价一个本机 POST RTT（毫秒级，运行按钮本有 loading 态）。测量效度 > 微小 UX 代价。

## Q5 · **code_mode 子率落地**（U4/U5 各一）
Python 默认积木模式，Blockly 生成代码的行级 diff 与手写不可比。子率只吃「窗内合法
版本对全不涉积木」的锚点（涉积木整锚排除）——给出可解释子群的读数。敏感性附录量，
不替代主 rate。

## D1 · 档位段**只作用于 navigator**（方案A，ai-prompt/v2）
研究自变量是「AI 领航员的支架渐退」。档位段同时拼给驾驶员时，教师降档等于逐步没收
学生的结对同伴——渐退操纵混入第二条作用通道，结果无法归因；且全部测量（hop/四分类/
uptake）都在 navigator 侧，驾驶员渐退是零测量覆盖的暗通道。SFM 的 guidance-fading 与
tool-fading 分离由此实现。窗口正开（ai_reply_log 真实数据 0 行），现在改可比性零成本。
红线不放宽：BASE_RULE 在所有角色×档位组合在场（19 条参数化断言钉死）。
候选 addon（req.scaffold 收权教师）不采用——已被更优的「无条件忽略」取代。

## D3 · 建模证据通道：**伪代码抽屉落地**（ct-rules/v4）
design_create 此前只在「Python+积木」可触发，而它扛 model 维 70%——该维有相当部分在测
「你选了哪个编辑器」，模式选择又与先前经验相关（选择偏差污染组间比较）。协变量
（lang/edit_mode，已落）只能事后控制；**测量工具本身必须补全**：IDE 新增「设计」抽屉
（任意语言/模式），保存 ≥3 行伪代码记一次 design_create（阈值语义同积木「拼出≥3块」：
多步才是分解；每作品一次防刷，公式 designs 饱和 k=3）。
后端零改动（design_artifacts 表与端点 2026-07 就在，0 行、无入口——又一处「有端点无
入口」断线，本次接通）。触发口径变更按 v1→v2 先例升 FORMULA_VERSION v3→v4；
真实数据 0 行，升位零成本。跨版本 design 计数不可直接比较。
