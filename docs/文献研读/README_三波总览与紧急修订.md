## 🔴 二、对你课题最致命的一条发现：AI 挤占的是人际互动

汤倩雯表 5-4 访谈里**三名学生连续印证同一现象**（我已核实原文）：

- 学生1：「和 AI 的互动多了但是**和老师没什么交流了**」
- 学生2：「AI 回答得有点模糊，我没太看懂，**也没来得及问老师**」
- 学生3：「AI 说得不太清楚，我就想找老师问，**但老师在帮别人**」

外加该文转引的「**削弱团队的互动与协作能力**」（Ulfsnes 等 2024）。

**对你的意义**：汤倩雯被挤掉的是**师生互动**；你的结对里可能被挤掉的是 **driver↔observer 互动**。
若 observer 遇到问题先问 AI 而不是问 driver，**结对就退化为「两个各自和 AI 对话的人坐在一起」——而 observer 的存在正是结对有效性的全部理由。**

**第二波给你的三个原创点（支架来源迁移 AI→同伴→自我、角色轮换×支架渐退、输出契约）全部建立在「学生真的会转向同伴」这个未检验的前提上。**

→ **对策（近乎零成本）**：加一个对抗性指标
`人际互动占比 = 生生对话轮次 /（生生 + 人机）`＋「observer 发起质疑次数」。
分母两个都现成（`collab.py` chat + `ai.py` 对话记录）。
**这是「支架来源迁移」是否真的发生的唯一验证量**——渐退若只是把 AI 关小而同伴互动没上升，该主张即被自己的数据证伪。
