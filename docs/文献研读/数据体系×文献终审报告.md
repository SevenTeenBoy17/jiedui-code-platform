### B. 走样（重点展开——每条都是「文献要求 → 实现偏差 → 后果」）

**B1.【结构性假阴性】人际互动占比分子恒 0（T1-12）——最危险的一条。**
定义层完全兑现（`learner.py:121-146` 分母口径与 T1-12 一致、分母为 0 返回 null 不硬造、ProfilesView 已展示），但 `POST /api/learner/chat/turn` 的调用方全仓只有测试（test_learner.py:241-243），web/src 零命中，CX 无 collab websocket——README L65 说的「collab.py 现成」锚错了仓库（collab.py 在 CodeAgent，不在 CX，正是第三波 §3.11 警告过的残留）。后果：真实课堂 peer_turns 恒 0，这个被称为「支架来源迁移的唯一验证量」的对抗性指标会把**管道断线读成假说被证伪**。对抗性指标带着结构性假阴性上线，比没有更糟。

**B2.【干预不在场】learner_state.scaffold_level 无消费方。**
档位有存储（满档 3 起步）、有建议器、有教师写入端点、有测试，但 `ai.py:220` 用的是客户端请求体的 `req.scaffold`，而 `StudioView.vue:308` 硬编码 `scaffold: socratic ? 0 : 1`。第二波 §4.0 明令的「组装 prompt 前按学生读档位，不再透传前端参数」未兑现。后果：学生实际体验只有前端定的 0/1 两档——**「三档渐退已实现」在此修通前是库表事实，不是学生体验事实**，论文任何此类表述都超前于系统。

**B3.【前端断线】roomId 不传 → goal_anchor 注入与 hop 在生产中永不触发。**

## 二、创新点终审

**结构关系先行**：①载体（时间轴）→ ②度量（渐退信号）→ ③证伪（对抗指标）→ ④边界（隐私约束）→ ⑤控制（干预回路）。**这套「度量/控制分离 + 自带证伪 + 隐私默认」的体系性才是可主张的创新**；单点拆开每一个都能被挑出先例或半成品。贡献句应写成第二波 §7.4 的形态——「给出了该领域系统性缺失（支架无操作定义、闭环无写路径、主张无证伪量）的操作定义与系统实现」——而不是五个并列的「首次」。所有新颖性主张只相对 19 篇文献底座（§1.3 教训：19 篇无人做 ≠ 无人做）。

### ① learning_round ⊥ 研究状态机 —— 组合创新（数据库层不变量化）
**成色**：双轨概念是方法学常识，文献里没人做只因没人有平台化研究层——这是工程空白不是理论空白；但落成 schema 级隔离（零共享字段、单轮互斥、exit_round 区分 None/0）是 19 篇无人做的。
**论文可用表述**：「已有研究的时间结构或为无终止闭环、或将有限性降至实施层；本研究将教学轮（主体为学生）与 DBR 研究迭代（主体为研究者）显式分离为正交双轨并落为互不共享字段的持久化结构。」——**「首次具备『同一学生跨轮同构测量』的数据载体」这半句在补 round 级快照前不要写死**。
**必须补**：learning_round 无 study_id/student_id 外键、`_freeze` 只按三期段不按轮、结题报告不消费 round_index——两轨正交到互相看不见。正交不等于无投影：需 round×study×student 的 join 视图与轮级快照，否则 T2-19 要求的答辩证据（「第 2 轮分解质量优于第 1 轮」）无数据可出。

### ② goal_anchor + hops —— 组合创新（宋双程答案锚的可信采集工程化）
**成色**：相对黄红涛 π* 有三条实打实的强项——可实现（π* 的 T/E/P 无可计算定义，hop 是落库可数事件）、采集可信（白名单拒伪造+公式不消费，度量信号与被激励量严格隔离——黄的纯理论构念从未面对过这个问题）、反泄露契约（锚点只注入 navigator、决策点不可说出、学生全线 403）。
**论文可用表述**：「以教师预设关键决策点为苏格拉底引导的正向参照，以服务端权威落库的追问轮数为支架强度的过程度量；相较黄红涛（2024, p.67）优化学习者行动序列的 π*，本机制优化的是支架强度序列 σ*——一字之差即『助学不代学』的形式化。」**必须紧跟**：「hops 与认知推进的对应关系为待验证假设，本研究报告其历时曲线而不预设单调下降。」
**必须补**：(a) 生产接线（B3，前端传 roomId）；(b) 论文中把 hop 如实定义为「navigator 追问轮数」而非「到达锚点的 hops」，否则审稿人拿宋双程原文一对照就现形；(c) hops 趋势接入 suggest_scaffold（度量→控制闭环）；(d) σ* 目标函数至今未写出，不可声称已形式化。

### ③ 人际互动占比 —— 立意真创新，实现半成品
**成色**：19 篇无人给自己的原创主张配对抗性指标，立意层面是真创新；但分子当前无数据源（B1）、计数单位语义不等值（一句「好的」与一次 AI 求助各记一轮）、「observer 发起质疑次数」被④架构性封死（判定「质疑」需要内容，而内容被设计性丢弃——③与④正面冲突）。
**论文可用表述**：分析必须**绝对量+比值双报告**（ratio 上升可能只是渐退关小 AI 的分母收缩；端点已返回原始数，这点做对了）；房间口径的「参与者全历史合计」近似须如实写。README 的「唯一验证量」必须降格为「**AI→同伴一跳的必要验证量**」——「→自我」段须与无支架 probe 表现联立才可证。
**必须补**：T0 级——协作层接 `add_chat_turn` 必须进开课前清单，与前测同级不可逆（开课后补不回互动基线）；chat 断线期报告端须把 peer_turns=0 标为「不可用」而非 0 值；observer 质疑二选一：客户端实时打标签只落标签不落原文（§3.7 形态，作研究展望），或降级为「observer 发言占比」并如实承认测不了「质疑」。

### ④ chat_log 纯元数据 —— 伦理-工程权衡，非分析创新
**成色**：不该按「分析创新」评——它是与吴晓彤「主动放弃跨会话记忆」同构的真实权衡：主动放弃能力换确定性。19 篇仅一篇有独立伦理段，「落地物比论文完整」的倒挂是正资产。**但代价必须清点**：话语分析全链条（CQ/EQ/RQ 编码、Murphy 框架、dialogue_codes、LSA）失去输入；连话轮长度都没有（刷屏「哦哦哦」与认真解释思路数据上等价）；最重的一刀砍在自己最独有的资产上——第二波认定「结对对话是 CX 独有的、11 篇全没有的动机标注源」，(代码 diff, 对话片段) 二元组的后一半被永久置空。
**论文可用表述**：「结对聊天采用纯元数据留存，在源头消除未成年人对话内容的 PII 暴露面；该设计以放弃话语级语义分析为代价，本研究据此 (a) 将过程话语证据的采集责任转移至质性访谈，(b) 将互动测量限定为轮次计数类指标并如实报告其分辨率上限。」
**必须补**：实时低置信度标签（只落标签不落原文，provisional/confirmed 两态）作为「研究展望」写，**不作为已有能力写**。

### ⑤ 支架策略「只建议不写库」教师确认制 —— 半真创新 + 制度性防御
**成色**：真硬的部分是被测试钉死的「禁读未验证测量」（过 T2-25 机制判据）与信号提取纪律（只采信有动作的失败、空窗不降档、升档优先于降档）。判定权归教师不是推责而是法理归位——面向未成年人、用无外部锚的测量驱动真实干预，机器自动写档才是不可辩护的选项。**但「橡皮图章」攻击面有三处**：建议→确认链数据断裂（PUT /state 不记来源，采纳/否决/没看见不可分）；采纳率分子分母双缺（连「被打脸」的机会都没有——比低采纳率更糟的是无法报告采纳率）；human-in-the-loop 教师仪表盘在 LA 领域是成熟范式，只能主张相对本底座的新颖性。
**论文可用表述**：「支架档位调整采取『机器建议—教师确认』双层制：建议层以源码级测试保证仅消费原始行为信号，从机制上（而非承诺上）切断『未验证测量驱动干预』的自反循环；档位写入权唯一保留给教师。」**写之前必须补建议留痕 + 采纳率预注册**（「采纳率如实报告为研究发现」；若执教者=研究者，只作过程描述不作外部效度主张），否则后半句撑不住答辩追问。

## 三、数据链断点（按答辩风险排序）

从原始事件到论文结论共五跳：事件→六维（基本闭合，缺 room_id）→四要素（闭合）→效标 r（断）→联合分析（三处断）→样本到结论（三条全断）。断点集中在**分析层 join 键**与**研究层旁证数据源**——恰是「你怎么排除竞争解释」被追问的位置。

**1. chat_log 无生产写入方（③的分子、④的全部意义、②⑤的结对侧证据都挂在它上面）**
最小补法：协作层聊天消息处调 `POST /api/learner/chat/turn` 或直调 `store_learner.add_chat_turn`；接通前，interaction 端点对「无 chat 通道」状态返回 `unavailable` 而非 0。**不可逆：开课后互动基线补不回，升格 T0 与前测同级。**

**2. scaffold_level 不进 prompt（渐退干预不在场）**
最小补法：`ai.py` 组装 prompt 前按 student 读 `learner_state.scaffold_level`，`req.scaffold` 降为教师覆盖参数；StudioView.vue:308 移除硬编码。

**3. roomId 前端不传（锚点注入与 hop 生产空转）+ ct_events 无 room_id 列**
最小补法：ai.ts 调用带 roomId（前端已知房间时）；`store.py` `_add_column(ct_events, room_id)`，ct.py:35 与 ai.py:232 各加一个实参（写入时 room 本来就在手上，~5 行）。**不可逆：开课后每天产生无法归房的事件。** 连带：开轮/结轮教师 UI，否则 round_index 恒 NULL、exit_task_passed 恒缺。

**4. α 范畴误用（被自己的订正文档打脸）**
最小补法：kind∈{pre,post} 能力卷停报 α，改报逐题难度 p + 点二列区分度（纯算术，符合 stats.py 不引 scipy 约束）；α 保留给将来的态度量表（第三波 §6-13 三分口径）；删 ct_v1_items.py:11 的「必须报 α」要求；α<0.6 的 caveat 规则同步改写。

**5. 档位无历史 + 建议无留痕（渐退自变量只剩最后一帧、采纳率双缺）**
最小补法（一套两表共建）：`scaffold_log(student_id, level_from, level_to, source, suggestion_id, round_index, room_id, ts)` + `policy_suggestion(student_id, ts, current_level, suggested_level, attention, reasons, requested_by)`；policy 端点 return 前落一行（现算改算完留痕，语义不变）；PUT /state 成功后追写 scaffold_log，请求体加可选 suggestion_id（NULL=教师自主改档）；`POST /policy/{sid}/dismiss` 区分 dismissed/ignored。后效指标零新增表：建议有 ts 后，「15 分钟窗内同类报错复现率」直接查 ct_events（错误前缀聚类与 learner.py:186-190 同源）——这是比采纳率更硬的主指标。

**6. 流失分析（complete-case 偏倚正在被平台固化为默认行为）**
最小补法：`study_members` 走 `_ensure_column` 加 `withdraw_reason`/`withdraw_phase`；补 withdraw 触发端点（现在连端点都没有）；`_caveats` 加差异性流失规则（两组流失率差 >10pp 硬写告警，参照汤倩雯 11.5pp 案例）；attrition 块补「流失者 vs 完成者前测均分」（最低限度敏感性检验，join 现成 ~10 行）。

**7. 认知负荷零数据源（三条件合取缺第三条腿）**
最小补法：新表 `cog_load(student_id, room_id, round_index, score, ts)`——**不要复用 ct_criterion**（唯一键每 phase 只容一行，且写入方相反：criterion 教师誊录、负荷学生自报）；单题 Paas 式 9 点自评，学生端 POST 带 CONSENT_REQUIRED 门禁，挂轮末/probe 后；`_caveats` 加合取规则：「档位降∧probe 不降∧负荷升≥1SD 记为『高负荷维持』，不计入渐退成功」；预注册措辞同步写死。

**8. 效标 r 管线三缺件**
最小补法：stats.py 加 `pearson_r` + `fisher_ci`（~30 行）；报告端 validity 块 join `ct_snapshots.dims × ct_criterion.total`（join 键现在就是通的）；`ct_criterion` 加 `dims` JSON 列（分维 r 须录入时打标，事后补不回）；export 加 `crit_{phase}_total` 列（现状是「脱敏导出」与「效标」两个子系统互斥）。**定位改写**：单班有效 n 现实 20-30，只有 r≥.5 才可能显著，而文献明说 r 可能 0.2-0.4——预注册把效标效度从「检验」改「估计」（点估计+Fisher-z CI+测量版 CONSORT），跨班合并 n≈80 后再谈检验。

**9. 互动占比无时间/轮维度**
最小补法：peer_turns/_ai_turns 加 since/until 形参；`_freeze` 的 behavior 冻结 peer_turns（当前只冻 ai_helps）；export 加 `{seg}_peer_turns` 列。chat_log 不必加 round_index 列（有 room+ts，用 learning_round 窗 join 够用）。

**10. room_id 自由文本无注册表**
最小补法：三处入口统一 `.lower()`（最低成本）；正路是 `room_member(room_id, student_id, joined_at)` 小表由协作层写入——同时把互动占比的「最诚实近似」升级为精确口径。协作层落地前完成即可。

## 五、诚实边界（数据永远回答不了的，别硬撑）

1. **单班做不出效标 r 的稳健检验。** 有效 n 20-30 之下这是注定不显著的检验；只能报点估计+CI 并预注册为「估计」。方案能保证的是把 r 算出来并公开，不能保证 r 好看——必须敢报低 r。
2. **hops ≠ 认知推进。** 当前 hop 是 navigator 回复计数，无到达锚点判定；即使收紧语义，「hops 历时下降=渐退发生」仍是待验证假设，与「AI 使用量下降」的区分只能部分做到。论文报曲线，不预设单调下降。
3. **「质疑」测不了，且是被④的隐私设计架构性封死的。** chat_log 无内容，observer 质疑次数、话轮均衡度（话量维度）、全部话语分析类研究在当前架构下不可能；动机标注源（CX 最独有资产）已永久置空。这是权衡的代价，如实写，别用「未来工作」掩饰它是不可逆的设计决定。
4. **支架来源迁移只能证「AI→同伴」一跳。** 「→自我」段需与无支架 probe 表现联立；peer/(peer+ai) 计数单位语义不等值，比值绝对值不可解释，只有历时方向可用。「唯一验证量」在论文中一律降格。
5. **采纳率若执教者=研究者，毫无外部效度**——只作过程描述；且在 teacher_action 留痕落地前，连「橡皮图章」质疑都无法用数据回应，这段历史（本轮之前）如实承认。
6. **「渐退有效」与「渐退发生」是两个主张。** 负荷数据接入前只能主张后者；接入后也只能排除「硬扛」这一个竞争解释，排除不了粘贴外源等其他路径（code_provenance 未做）。
7. **19 篇是本课题的文献底座，不是领域全集。** 双轨结构、human-in-the-loop 确认制的新颖性只相对本底座成立；结对编程零底座的翻车（T3-27）随时可能在别的创新点复演。所有「无人做过」改写为「所研读文献中未见」。
8. **「首次具备同构测量的数据载体」在轮级快照与 round×study join 落地前只对了一半**——正交做到了，投影还没有。写论文时按当时代码实况措辞，代码现状必须以实际 grep 为准（§8·12），本报告即是按此纪律产出的。
