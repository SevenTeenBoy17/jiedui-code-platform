## 2. ① CT / 思维评价：维度操作定义、工具条目、证据链每一环、信效度数值（细读）

### 2.1 构念：测的是「倾向（disposition）」，写的是「能力（ability）」——构念滑移贯穿全文

- 工具是**《加利福尼亚批判性思维倾向问卷》（CCTDI）**的改编版，罗清旭、杨鑫辉译校本（p.37, PDF 46, line 1487-1500）。作者自己写明「本研究主要关注学生批判性思维的**变化**」「对学生批判性思维**倾向**进行测量」。
- 但第 7 章回答研究问题时写的是「**1. 整体提升批判性思维能力**」「三个班级在批判性思维各维度及均分上均实现了显著性提升」（p.85, PDF 94, line 3653-3657）；摘要写「基于智能学伴的生成式探究学习对批判性思维的提升效果优于通用大模型」（p.I, PDF 2）。
- **CCTDI 测的是「愿不愿意这么想」，CCTST 才测「会不会这么想」**。作者在 p.37 明明并列提到了 CCTDI / CCTST / 康奈尔 X 级三种工具，却只选了倾向卷，然后全文按能力卷解释结果。
- 更麻烦的是：**倾向卷是自评李克特**，而实验组学生每周被一个"不停反问你"的智能体训练了 6 节课——自评"我勇于寻找事实真相""我不害怕在课堂上提问"上升，完全可以是**任务熟悉度/社会赞许性/需求特征（demand characteristics）**的产物，而不是思维本身变了。
- ⚠️ **对用户的直接警示**：这与 CX 平台「六维行为分 → 计算思维水平」是**同一类范畴滑移**，只是方向相反——03 是「自评倾向 → 说成能力」，CX 是「行为频次 → 说成能力」。两者都缺中间那一跳的独立证据。第一波综合第 38 行说 CX 的链"比它们更假"，这个判断在 03 这里需要修正：**03 的链在「构念标签」这一环和 CX 一样假**，只是它多了一层量表外衣显得体面。

### 2.2 维度操作定义：六维、每维仅 3 题、少了 CCTDI 原本的一维

作者「根据实验学校具体情况对问卷进行调整，选择**真理性、系统性、思想开放性、分析性、自信性、好询问**六个方面」（p.37, PDF 46, line 1497-1498）。

- CCTDI 原版为 **7 维**：寻求真理、开放思想、分析性、系统化能力、自信心、求知欲、认知成熟度。**03 删掉了「认知成熟度（Maturity）」，且全文未给删除理由**。删一维不解释，是量表改编的硬伤。
- **全文没有给出任何一维的操作定义**。表格里只有维度名，正文里只有「寻求真理性 = 探索问题和主动验证答案的能力」这类**在讨论段临时给出的、非事前定义的解释**（p.67, PDF 76, line 3061-3063）。这与第二波笔记里对「维度必须有事前操作定义」的要求正好相反。
- **题项数**：附录 A（p.97-98, PDF 106-107, line 4106-4240）共 **18 题**，六点李克特（非常不赞同→非常赞同），与表 6-1 的「项数 18」一致。**18 题 / 6 维 = 每维仅 3 题**。
  - 3 题/维是**分维度报 α 的下限之下**——作者**只报了总量表 α=0.817，从未报任何一维的 α**，却在第 6 章逐维做 t 检验、逐维报 Cohen's d、逐维下结论。**用未验证信度的 3 题小分量表去支撑全部核心结论，是本文最系统性的信度缺陷。**
  - 逐题看还有构念纯度问题，举三例（原文行号在括号）：
    - 第 1 题「处理复杂的问题时，我也能保持冷静」（line 4110）——这是**情绪调节**，不是批判性思维任一维。
    - 第 13 题「当我想到有创意的点子时，我会很满足」（line 4199）——这是**创造动机/情感体验**。
    - 第 18 题「解决难题很有趣」（line 4234）、第 17 题「我很期待遇到挑战」（line 4227）——**学习兴趣/挑战偏好**。
  - 也就是说 18 题里至少 4 题偏离批判性思维构念，而每维只有 3 题——**一维里混进一道无关题，就污染 1/3 的分量表**。

### 2.4 证据链逐环拆解（每一环都点出「这一环撑得住什么、撑不住什么」）

作者的证据链名义上是五环：

```
①改编 CCTDI 前测 → ②6节课干预 → ③后测 → ④组内配对t + Cohen's d
                                  ↘ ⑤对话 Murphy 编码 → ⑥LSA 转移图 → ⑦典型案例/学习单截图/访谈
```

**环①→③（量表前后测）**
- 前测：表 6-3（p.60-62, PDF 69-71, line 2454-2613）。**批判性思维均分 F=0.357, P=0.701**，三班基线均分无差异 ✅。
- **但**：维度一（寻求真理性）**F=3.218, P=0.043**；维度四（分析性）**F=3.826, P=0.024**——**两个维度在前测就已显著不齐**（line 2617-2618 作者自己写明了）。
- 后测：表 6-4（p.61-63, PDF 71-72, line 2622-2783）。**六个维度 + 均分，全部 P>0.05，没有任何一项组间显著**（最大的 P=0.647，最小的差异 F=0.05）。

**环④（配对 t + d）**
- 三个班**全部维度全部显著**（P<0.05），**包括对照班豆包**（表 6-8, p.66, PDF 75, line 2964-3010）。也就是说：**"用豆包也显著提升批判性思维倾向"**。
- 这一环唯一撑得住的结论是：「三个班在 3 个半月里自评倾向都涨了」。它**撑不住任何组间比较**，因为没有交互检验。

**环⑤⑥（对话编码 + LSA）**
- 只编码了**两个实验班**（表 6-10, p.69, PDF 78, line 3139-3183）。**对照班的豆包对话录屏明确存在**（p.54, PDF 63, line 2236-2237 提到"对照班学生与豆包的聊天录屏的对话分析"），**但从未用同一套 Murphy 框架编码，也从未进入表 6-10**。
- ⚠️ **这是证据链最假的一环**：过程性证据只在实验组内部做了「第一次 vs 第六次」的**时间对比**，缺了**同期对照**。任何「学生在 3 个半月里从辨识/理解走向分析/创造」的趋势，都可以被「六年级学生 3 个半月的自然发展 + 对同一任务类型的熟悉」解释。作者在 p.87（PDF 96, line 3724-3728）的局限里承认了长期效应未知，**但没承认这一条**。

**环⑦（质性）**
- 访谈只做了**对照班**（学生 A–E，p.76, PDF 85, line 3382-3389）；学习单只做了**作者选定的"典型"截图对比**（图 6-5 / 6-6，p.74-75）。
- **学习单从未被评分**（附录 F, p.105, PDF 114, line 4102 起，是空白填写单，**无 rubric、无锚点、无评分者**）。
- 所以质性证据**全部指向同一个方向、全部由作者单方选样**，它是**佐证性（confirmatory）**的，不是**可证伪（falsifiable）**的。见 §4.1，这正是第一波读反的地方。

### 2.5 ⚠️ 致命问题 A：用「组内 Cohen's d」排序三个组，结论与原始增量相反

这是本篇最大的方法学漏洞，而且是**可以用作者自己的表格当场反驳**的那种。

作者的核心结论（摘要 + p.85, PDF 94, line 3654-3657）：
> 「在『批判性思维均分』的效应量上，使用智能学伴的两个实验班均高于使用『豆包』的对照班，且『推理之王』效果优于『苏格拉底学伴』。」

把表 6-6 / 6-7 / 6-8 的**均分行**并排（p.65-66, PDF 74-75）：

| 班级 | 前测均分 | 后测均分 | **原始增量** | 组内 Cohen's d | 排名（按 d） | 排名（按增量） |
|---|---|---|---|---|---|---|
| 苏格拉底学伴 | 4.112 | 5.024 | **+0.911** | 0.953 | 2 | **1** |
| 推理之王（CER） | 4.217 | 4.991 | **+0.774** | **1.230** | **1** | 2 |
| 豆包（对照） | 4.238 | 4.967 | **+0.729** | 0.755 | 3 | 3 |

**推理之王的「最优」完全来自分母。** 组内 d = 差值均值 / 差值标准差。推理之王 d=1.23 对应差值 SD ≈ 0.629；苏格拉底 d=0.953 对应差值 SD ≈ 0.956。也就是说：**推理之王班涨得更少，但涨得更整齐**；作者把「个体差异小」误读成了「效果好」。

- **组内 d 依赖各组自身的变异度，跨组不可比**，这是效应量使用的基本约束。要做组间比较，正确工具是 **组×时交互（重复测量 ANOVA）或以前测为协变量的 ANCOVA**，两者本文都没有。
- 更狠的一刀：**后测 ANOVA 的均分 P=0.951**（表 6-4, line 2767-2770）。三个班后测均分 5.024 / 4.991 / 4.967，差距 0.057 分（六点量表），**统计上和实质上都是零**。
- 所以本文对研究问题二的核心回答，**在本文自己的数据里没有支持**。

📌 **可直接写进用户论文的句式**（见 §5）：这一条同时证成了用户「四角测评」必须报 ANCOVA/交互项、Cohen's d 只作辅助的设计选择。

### 2.6 ⚠️ 致命问题 B：把前测组间不齐 → 后测组间齐，读成「干预有效」（回归均值伪装成效应）

原文 p.62（PDF 71, line 2787-2791），逐字：
> 「但前测时三个班级出现显著性差异的维度一 P 值为 0.647>0.05，维度四 P 值为 0.930>0.05，因此统计结果不显著……**表明实验处理有效消除了前测中存在的组间差异**，即使用『苏格拉底学伴』的实验班在寻求真理性维度进步显著、使用『推理之王』的实验班在分析性维度进步显著。」

三重错误叠在一句话里：

1. **「不显著」不是「相等」的证据**。P>0.05 只说明没检出差异，不能推出「差异被消除」，更不能反推「谁进步了」。要主张等价需做等价性检验（TOST）。
2. **典型的回归均值（regression to the mean）**。看前测（表 6-3）：
   - **寻求真理性**：苏格拉底班 3.968（**三班最低**）→ 后测 5.275（三班最高），d=1.016（**该班全维度最大**）。
   - **分析性**：推理之王班 3.803（**三班最低**）→ 后测 5.167，d=1.023（**该班全维度最大**）。
   - **两个班各自的"招牌效应"，恰好长在它自己前测显著最低的那一维上。** 这是回归均值的教科书形状。
3. **叙事被硬套到理论上**。作者随后花整整 1.5 页（p.67-68, PDF 76-77, line 3061-3112）解释「为什么苏格拉底式提问特别提升寻求真理性」「为什么 CER 特别提升分析性」——这些机制解释建立在一个统计伪影上。而作者在同一段还得为**推理之王在寻求真理性上只有 d=0.355（三班最低）** 找理由：「可能由于 CER 模型中问题设置的框架化和逻辑性较强，削弱了学生在寻求答案时的主动探索意识」（line 3064-3066）。**同一个班，前测在该维最高（4.553）→ 涨得最少，也是回归均值；作者却给了一个理论解释。** 前测最高的涨得少、前测最低的涨得多——这是本文**六个维度全都成立**的规律，不需要任何教学理论。

### 3.4 支架：**没有渐退，反而是逐轮"增厚"**——这是对用户「渐退式支架」最有价值的反例

这是本次补读对用户论文最有战术价值的一条。

**表 5-2「智能学伴部分设定调整前后对比」（p.51-52, PDF 60-61, line 2104-2179）**，试点测试后的四处修改，**全部是加支架、加兜底，没有一处是撤支架**：

| 技能 | 调整前 | 调整后（**新增部分**） | 方向 |
|---|---|---|---|
| 技能2 解答问题 | 不直接答，追问 1 个问题；学生答对才停 | **追问前给到学生必要的简短的知识输入**；**学生输入"我明白了"也停止追问** | **加前置知识 + 加退出口** |
| 技能3 反馈讲解 | 引导找证据、鼓励、适当总结 | **学生说"请告诉我答案"时给更多提示、降低难度**；**一个问题应在 6 轮对话以内让学生得到答案和解释** | **加提示 + 加轮次上限** |
| 技能5 伙伴的关怀 | 情感反馈、亲切、纠错 | **学生输入"不知道"→更细致讲解与提示**；**连续 5 次"不知道"→直接给出问题的详细解答并确认理解** | **加兜底（明确的代学阈值）** |
| **技能6 分层引导**（新增，仅推理之王） | — | 推理环节按**准确度与参与度**三档：低→直接告知推理过程并确认理解；中→给更多提示、问补全式问题；高→开放式追问完整推理过程 | **加分层** |

**三点分析：**

1. **迭代方向 = 增厚，不是渐退。** 驱动力是试点数据：学习单完成度低（p.47-48, PDF 56-57, line 2026-2031「大多数同学只完成了学习单中第一、二个问题」）、学生反馈「一直在反问，不知道如何回答」「我觉得这种回答方式很绕」（p.49, PDF 58, line 2048-2050）、以及「更快告诉我答案」「直接说答案」的诉求（p.50, PDF 59, line 2076-2078）。**六年级学生在纯苏格拉底式追问下会挫败并放弃。**

2. **技能6 的"分层"是横向差异化，不是纵向渐退。** 它按**学生水平**（准确度与参与度）分三档，而**同一个学生在 6 节课里不会自动从"低档"升到"高档"**——因为每节课的智能体是**重新搭建**的（见 §3.6），没有任何跨课记忆。**分层是静态的、单次会话内的。**

3. ⚠️ **「助学不代学」被明确开了口子**：`连续 5 次"不知道" → 给出详细解答`。这既是必要的心理兜底，也是**一条可被利用的绕过路径**（学生连打 5 次"不知道"就拿到答案）。原文没有讨论这个滥用风险。

📌 **对用户论文的用法**：不要把 03 当"渐退式支架"的支持文献（它不是）。**把它当"为什么必须有兜底/地板机制"的必要性论据**——用户的渐退式支架若不配一个 03 式的失败阈值（连续 N 次无进展 → 降级到示范/直接讲解），在初中生群体上会重演 03 试点的挫败。同时用户可以主张改进：**把 03 的静态三档分层升级为跨会话画像驱动的动态渐退**——这恰好是用户「学情感知 + 支架推送」两职能的存在理由。

```
【人物设定 · 角色】 初中信息技术课智能学伴，苏格拉底式启发教学，
                    每次仅提出一个问题，问题维度逐步递进，引导学生为主张找证据，
```

### 4.1 ❌ **说错（较严重）**：把 03 的质性证据说成「可证伪的三角」

1. **访谈对象只有对照班**（学生 A–E，p.76, PDF 85, line 3382-3389），访谈问题是「为何看不懂专业术语也不继续追问」——**是带着结论去找解释**，不是去挑战结论。

**但 idea 本身仍然成立**——只是**来源应改为 07_许家奇**（第一波自己写了 07「诚实止步于过程模式、不塌缩成分」），而 03 应改为**反例引证**：「已有研究虽同时采集量表、对话编码与质性材料，但三类证据均由同一预设组织、缺乏互斥性判据，因此未能形成真正的三角互证（杨瑞珍, 2025, p.74-77）」。这个改写反而更有力。

### 4.2 ❌ **高估**：把 α=0.817 / KMO=0.806 当"正向模板齐备可抄"

第一波 line 33 把 03 列为信效度正向模板。补读后必须加四条限定（详见 §2.3）：
- α/KMO/Bartlett 全部来自 **n=40 的预研究班**，不是 124 人实验样本；
- **被试:题项 = 2.2:1**，远低于 EFA 常规要求；
- **只有总量表 α，无任何分维度 α**，而所有结论都是分维度下的；
- **没有做 EFA 载荷 / CFA**，"六维"是抄的不是验的。

⇒ 可抄的是**流程模板**（"改编量表 → 预研究 → SPSS 信效度 → 再正式施测"这个顺序），**不可抄的是"报这三个数就算做了信效度"这个标准**。

### 4.3 ❌ **不加批判地推荐了一份有错的编码手册**

第一波 line 94：
> 「03 表 4-3 那份逐行标注示例**可直接当标注手册模板**。」

表 4-3（p.39-42, PDF 48-51, line 1579-1916）共 40 轮，逐行核查后发现**编码与解释互斥/可疑的至少 4 处**：

| 行 | 学生话语 | 给的编码 | 给的解释 | 问题 |
|---|---|---|---|---|
| 6 | 「**是的**」 | **A（分析）** | 「分析：确认这些部分可以看作模块」 | 两字肯定被编为最高频的"分析"。若"是的"算分析，A 类目就没有区分度了 |

## 6. 该文献自身的方法缺陷（判定依据汇总）

按严重度排序。每条给出**判定依据**（原文位置 + 可复核的算术），不做无据指控。

### 🔴 D1. 主结论「推理之王 > 苏格拉底 > 豆包」在本文数据中不成立
- **依据**：表 6-6/6-7/6-8 均分行 → 原始增量 0.911 / 0.774 / 0.729，排序与 d 排序（0.953 / 1.230 / 0.755）相反；表 6-4 后测均分 ANOVA P=0.951。
- **判定**：组内 Cohen's d 的分母是各组自身的差值 SD，跨组不可比；无组×时交互检验、无 ANCOVA。**不可引用该结论。**

### 🔴 D2. 两个「招牌效应」落在各自前测显著最低的维度上（回归均值）
- **依据**：表 6-3 寻求真理性 P=0.043（苏格拉底 3.968 最低）；分析性 P=0.024（推理之王 3.803 最低）。表 6-9 中这两组各自的最大 d 恰好是 1.016 与 1.023，就在这两维上。
- **旁证**：推理之王在自己前测最高的寻求真理性（4.553）上 d=0.355 最低——作者却给了理论解释（p.67）。**六维通看，前测越低涨得越多，无一例外。**

### 🔴 D3. 把「后测不显著」解读为「干预消除了组间差异」
- **依据**：p.62 原文（line 2787-2791）。
- **判定**：不显著 ≠ 等价；需 TOST。且该句还从"不显著"反推出"谁进步显著"，逻辑不成立。

## 7. 研读时的思考痕迹

**T1（读到摘要时）** — 第一印象是"这就是一篇标准的准实验+DBR 硕论"。但摘要里那句「在寻求真理性和分析性两个子维度上优势明显」和后面「整体而言，CER 版效果更优」让我起疑：**两个子维度、两款学伴，恰好一款一个**，太整齐了。整齐往往意味着数据在配合叙事，而不是叙事在跟随数据。带着这个疑问去查表 6-3，果然——那两维正是前测显著不齐的两维。

**T2（读第 3 章时的期望落空）** — 我本来期待 3.2 节会给出"两款学伴的完整提示词 diff"，结果只有一句「『苏格拉底学伴』的设定逻辑中不涵盖『主张-证据-推理』的设定逻辑」（p.29）。**只给了一句话的操纵说明，但这句话本身是干净的**——单变量操纵。这是全文设计上最扎实的一处，与它统计分析上的松散形成强反差。这提醒我：**方法学缺陷是分布不均的，不能因为统计烂就否定设计。**

**T3（读到表 5-2 时的转向）** — 这是本次补读的转折点。我原本按第一波的框架在找"评价方法"，读到表 5-2 才意识到**这篇论文真正的价值在工程迭代日志上**。四处修改全部是"加"，没有一处是"减"——而用户模型的核心承诺之一是"渐退式支架"。**一篇同学段、同技术路线的研究，在真实课堂里被迫朝相反方向走**，这比任何理论论证都更能说明"渐退"需要配套条件。我在这里改变了整篇笔记的重心。

**T4（发现 d 排序反转时）** — 我先算了 5.024−4.112=0.912，再算 4.991−4.217=0.774，愣了几秒。**苏格拉底涨得更多，但结论说推理之王更好。** 回去看 d 的定义才明白是分母的事。这一刻我确认：第一波 line 72 那句"组内 d 好看但组间 P 不显著"虽然方向对，但**远远低估了问题的严重性**——不是"d 好看但不能推广"，而是"**d 的排序本身就把结论翻了个面**"。

**T5（表 6-10 与表 6-12 对撞）** — 读表 6-12 说"无关话题完全消失"时我下意识回翻表 6-10，看到 I=6。第一反应是自己看错了。核对三遍后确认矛盾。**但更有意思的是反方向那一半**：苏格拉底班 I 从 25 掉到 2，作者却说"比例进一步上升"。我意识到作者是**只看 LSA 图、不回看频次表**在写结论。这暴露的不是粗心，而是**方法论上的一个真实陷阱**——转移概率的显著性和行为的频次是两件事，稀疏时前者会剧烈失真。这条对用户 CX 上任何序列分析都是硬约束。

**T6（读附录时的意外）** — 我本来只是想抄一下 18 道题的原文，结果在附录 B 撞见"二、知识小测验"三道客观题。**明确写着向实验班与对照班都发**。我立刻全文 grep，确认结果章零命中。那一刻我的判断从"这篇论文统计做得糙"升级为"**这篇论文有选择性报告问题**"——因为那三道题是唯一能反驳 6.3.1 全节论证的数据。这也让我对第一波"03 是可证伪三角正例"的结论彻底翻案。

**T7（读第 7 章图 7-1 时）** — 看到「师-生-机」四个字时是真的一惊。用户的模型叫「师—机—生」。**这是必须处理的近邻文献，不处理会被审稿人直接点出来。** 但仔细比对后我反而松了口气：03 的三环节是**时间上的前中后**，用户的四环两分是**主体上的职责分离**；03 的智能体是单 Agent 六技能（按说话方式切），用户是四职能（按数据产出切）。**差异是实的，而且能说清楚。** 关键是用户必须主动引、主动划界，不能装作没看见。

**T8（回看第二波的"四缺口同一根因"）** — 03 是这个诊断的**极限案例**：它连"跨节课"都不跨，每节课换一个新智能体。但恰恰因为它这么极端，它把后果暴露得最清楚——它在表 2-1 里郑重写下"最近发展区适配"，在技能 6 里做了三档分层，**却没有任何机制知道一个学生上节课在哪一档**。所以它的"适配"永远只能在单次会话的几轮对话里现场判断。**这不是实现不到位，这是架构上不可能。** 用户的画像持久层不是锦上添花的功能，是这一整套教学承诺能否兑现的前提。

**T9（关于该不该继续引它）** — 结论：**引，但要分层引**。它的**模式结构、工程细节、教师访谈、工具异化现象描述、局限自陈**都是好料；它的**任何统计数值和组间比较结论**都不能碰。这种"部分可引"其实比"完全可引"更有用——因为把它的方法缺陷写进用户的研究设计论证里，本身就是一段有说服力的文献评述。

## 8. 苏格拉底式追问链

### 追问链 1｜"它到底证明了什么？"

**Q1：本文声称"基于智能学伴的生成式探究学习对批判性思维的提升效果优于通用大模型"。这句话的直接证据是哪一张表？**
→ 不是表 6-4（后测 ANOVA，全部不显著），而是表 6-9（三班组内 Cohen's d 对比）。

**Q2：表 6-9 里的 d 是组内还是组间？**
→ 组内（配对前后测）。

**Q3：组内 d 的分母是什么？**
→ 该组自身**差值分数的标准差**。

**Q4：那么两个组的 d 谁大，取决于什么？**
→ 取决于两件事的比值：增量大小 **和** 该组个体反应的整齐程度。**两组的分母不同，所以 d 不可比。**

**Q5：如果只看分子（增量），排序是什么？**
→ 苏格拉底 +0.911 > 推理之王 +0.774 > 豆包 +0.729。**与本文结论相反。**

**Q6：那本文对研究问题二的回答，还剩下什么是数据支持的？**
→ 只剩「三个班在 3 个半月里自评批判性思维倾向都显著上升」。而这个结论**包括对照班**，因此**不能归因于智能学伴**。

**Q7：如果要真正回答"哪种学伴更好"，最小必要的分析是什么？**
→ 以前测为协变量的 **ANCOVA**，或 3(组)×2(时) **重复测量 ANOVA 看交互项**；再加一个可反驳自评的**客观结果测量**——而这个测量**本文已经采集了（附录 B 知识小测验），只是没报**。

> 📌 **对用户的转化**：CX 平台的 study.py 研究层状态机应在 `posttest → closed` 迁移前设一道门禁：**若无组×时交互检验结果，或无独立于自评/行为分的客观锚，则阻断迁移**。这道门禁的立论依据就是 03 这条追问链。

### 追问链 2｜"支架为什么没有渐退？"

**Q1：本文的理论基础第二条是支架理论、最近发展区。渐退（fading）是支架理论的固有成分吗？**
→ 是。Wood/Bruner 的原始表述里，撤除支架与搭建支架同等重要。

**Q2：本文表 5-2 的四处迭代，有哪一处是撤支架？**
→ 零处。四处全是加：加前置知识、加提示、加轮次上限、加"5 次不知道给答案"、加分层。

**Q3：为什么会朝反方向走？**
→ 试点数据逼的：学习单完不成（p.47-48）、学生说"很绕""一直在反问不知道如何回答"（p.49）、明确要求"直接说答案"（p.50）。**六年级学生在无兜底的纯苏格拉底追问下会挫败退出。**

**Q4：技能 6 的三档分层算渐退吗？**
→ 不算。它是**横向差异化**（不同学生不同档），不是**纵向渐退**（同一学生随时间撤支架）。

**Q5：那有没有可能它其实是纵向的，只是没写清楚？**
→ 不可能。因为**每节课的智能体是单独重建的**（p.28），且分层依据是"学生**其他回答**的准确度与参与度"——"其他回答"指的是**本次会话内的其他轮次**。**没有跨会话状态，纵向渐退在技术上不存在。**

**Q6：那么"渐退式支架"要在初中生身上成立，缺的是什么？**
→ 两样：(a) **跨会话的学习者状态**，用来决定"现在该退到哪一档"；(b) **失败地板/兜底机制**，用来防止退过头导致挫败退出——**03 的"连续 5 次不知道 → 给详细解答"就是地板的原型**。

**Q7：地板机制会不会变成绕过通道（学生连打 5 次"不知道"骗答案）？**
→ 会。**03 没有讨论这个风险。** 用户应把"地板触发"作为**保真度指标落库**（谁、哪一题、第几次触发），既做教学预警，也做干预保真度证据——这正好填上 D14 指出的空白。

> 📌 **转化**：`ct.py` / `study.py` 应新增 `scaffold_level`（当前档位）+ `floor_triggered_count`（兜底触发次数）两个跨会话字段，前者驱动渐退，后者做保真度与作弊检测。**这是从 03 的失败里直接长出来的设计需求。**

### 追问链 3｜"这份编码手册能不能直接抄？"

**Q1：第一波说表 4-3 可直接当标注手册模板。它的 Kappa 是 0.84，够高吗？**
→ 0.84 是好数字。但 Kappa 度量的是**两位编码者是否给出相同标签**。

**Q2：两个人都把"是的"编成"分析"，Kappa 会下降吗？**
→ 不会，反而升高。**一致性高与类目有效是正交的。**

**Q3：表 4-3 里有几处编码与它自己的解释冲突？**
→ 至少两处硬冲突：行 18（解释写"与模块化无关"却编 R 而非 I）、行 20（编 U 而解释写"分析"）。另有两处类目边界可疑：行 6「是的」→A、行 10/40「明白了」→U。

**Q4：这些误编会影响本文的哪个核心证据？**
→ 表 6-10 的 A（分析）占比。A 从 13.53% 涨到 35.96% 是"走向高阶思维"的主证。**若确认性短语被计入 A，涨幅被虚增。**

**Q5：这个框架缺了什么类目？**
→ **元话语 / 应答（acknowledgment）**。"是的""明白了""理解了""不知道"这类既非批判推理、也非离题的话语，在原框架里无处安放，只能被硬塞进 R/U/A。

**Q6：如果用户把这套框架搬到结对编程语料上，还会缺什么？**
→ 第一波已正确指出要补**协作协调**类（"你先跑""换我开"）。补读后再加两条：(a) **代码/执行事件话语**（"跑起来了""报错了"）在编程语料里占比会很高，也无处安放；(b) **driver/observer 角色的话语功能天然不对称**——observer 天然多 E（评价）、driver 天然多 C（创造），**必须按角色归一化，否则"谁的 CT 更高"完全由座位决定**。

**Q7：那 03 的哪一半编码框架是可以直接抄的？**
→ **表 4-2 的 CQ/EQ/RQ（智能体提问类型）**。它编的是**机器的输出**，机器输出由提示词决定、稳定、可穷举，**类目效度问题小得多**。而且它的用途更值钱：**它是"支架推送职能有没有按设计工作"的保真度证据**。

> 📌 **转化**：用户 CX 的 `ai.py` 双 persona 应做一套 **persona-fidelity 编码**（ai_navigator 是否真的没写整段代码、是否真按 CT 四要素顺序追问），抽样 X% 对话由两位教师盲编、报加权 Kappa。这比再做一份学生话语编码更划算，也直接回应第二波"四职能无数据契约"的诊断——**保真度编码就是契约的验收测试。**

### 追问链 4｜"为什么那三道客观题没有被报告？"

**Q1：附录 B 的三道知识题测的是什么？**
→ 系统与模块关系、连续量→开关量的阈值转换、输入-计算-输出环节。**正是六节课的核心知识点。**

**Q2：它们对谁发的？**
→ p.37 明写"向实验班与对照班发放"。**三班齐全，可做组间比较。**

**Q3：如果结果是"三班无差异"，本文的哪一段会塌？**
→ 6.3.1「工具异化」整节（p.74-77）。该节论点是"豆包班只是搬运、没真懂"，其证据是两张作者选的学习单截图 + 教师一句调侃 + 5 位学生课下访谈。**三道客观题若无差异，"没真懂"就失去客观支持。**

**Q4：如果结果是"实验班显著更高"，作者有理由不报吗？**
→ 没有。那会是全文最强的一条证据。**不报本身就是信息。**

**Q5：那作为读者，正确的处理是什么？**
→ 不指控动机，但**必须在引用时标注该测量存在且未报告**，并把该节论证降级为"定性观察"。同时——**这正是用户不能重蹈的坑**：用户的四角测评时间线（前测→作品测评→后测→素养画像）里，**"作品测评"就是那个客观锚**。

**Q6：怎么保证用户自己不会在结果不利时悄悄不报？**
→ **把测评编排进状态机而不是编排进论文写作流程。** `study.py` 的研究层状态机若把"作品测评分已录入"设为 `posttest` 的前置条件、把"四类结果均已生成快照"设为 `closed` 的前置条件，**弃报在系统层面就做不到**。这是把学术诚信写成代码约束。

> 📌 这条追问链的产出是一条具体的工程需求，且它的正当性来自一篇真实文献的真实失误。

### 追问链 5｜"03 的模式能不能直接搬到结对编程？"

**Q1：03 的三环节里，哪一环最依赖学科？**
→ 第一环（教师建知识库、写引导思路）。表 5-3 的六课引导思路全是**概念探究型**（原理理解），不涉及代码产出。

**Q2：编程课的"共创讨论"环与 03 的有什么本质不同？**
→ 编程有**可执行的外部反馈**（运行结果、报错）。03 的探究里，学生的唯一反馈源是智能体的肯定/否定；编程里，**编译器和测试用例是不会奉承人的第三方评判**。

**Q3：这对智能体角色意味着什么？**
→ 03 的学伴必须同时承担"提问者"和"正确性裁判"（技能 3 明写"明确学生回答的正确与错误"）。**编程场景可以把裁判权交给运行结果**，学伴从而能更纯粹地做苏格拉底式追问——**"助学不代学"在编程里比在概念课里更容易守住**。

**Q4：03 的模式里，人-人协作在哪儿？**
→ 只在"代表分享"和"全体复盘"两个**全班环节**。**探究过程本身是 1:1 的人机对话。** 教师访谈里提过"以小组合作的形式还是个人探究，需要斟酌"（p.26），最终选了个人。

**Q5：加入 driver/observer 结对后，03 的哪些结论会失效？**
→ 至少三条：(a) Murphy 编码的类目分布（新增协作协调话语）；(b) "无关话题 I 减少 = 专注度提升"的解读（结对中的社交话语未必是离题）；(c) 个体归因——**"这份作品/这段推理体现谁的 CT"在 1:1 场景下不是问题，在结对里是核心难题**。

**Q6：那 03 对结对编程还剩什么可迁移？**
→ 三样：**三环节的权责骨架**（教师前置搭架 / 中段共创 / 后段共研反思）、**表 5-2 那套"支架增厚 + 兜底阈值"的迭代方法**、**表 4-2 的智能体提问类型编码**。这三样都与学科无关。

**Q7：那用户论文里 03 应该被放在哪个位置？**
→ **文献综述里作为"师-生-机模式"的近邻前作 + 研究设计章里作为"为什么必须做 ANCOVA 与客观锚"的方法学反例 + 讨论章里作为"AI 依赖/工具异化"的现象学支持。** 三处，三种用法，**不放在"测评方法"那一节**——那正是第一波把它放错的地方。
