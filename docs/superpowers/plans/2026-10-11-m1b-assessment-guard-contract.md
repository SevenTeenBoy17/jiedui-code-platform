# M1b1 — 独立测评的 AI 内容帮助门禁

本片是 M1b 的前置小片，不宣称可信会话已接入 AI。M1a 的 `not_connected` 保持不变；下一片才处理会话、轮次、历史材料与房间权限。Supervisor 继续暂停。

## 范围与来源

- 依据已批准方案 M1；仅修改 ai.py、study.py、store_study.py，新增 assessment_access.py 与 test_assessment_ai_guard.py，本合同、progress.md 和 `.runtime/m1b-assessment-guard-20261011/**`。
- 不改 UI、提示词 v2、D1 档位、实验分组、能力评分、实际学生数据或部署配置；不新增正文日志、数据库表或新的保存期限。
- 历史研究的“强制苏格拉底 / 通常 AI”不改为“有 AI / 无 AI”。本片只保护平台已有独立测评卷的已开启作答窗口。

## 服务端状态规则（assessment-ai-guard/v1）

1. 成功授权取卷时，原子验证本人推送、实时同意、窗口、未提交，并写原有首次取卷记录。它证明取卷，不证明开始思考、持续作答或独立能力。
2. 各种 kind（pre/post/probe/delayed/其他已有独立卷）均保护。仅收到推送或打开列表不触发；每个学生按全量已开启记录查询，不依赖页面、IP、角色图标、session、房间、推送最新 50 条或客户端完成标记。
3. 已取卷且未真实提交、窗口仍可作答时，聊天和生图均不调用模型、不进入编程型 fallback、不写正常 ai_help/hop/ai_reply_log。返回 HTTP 423 和固定中文流程说明；另提供只读流程帮助接口，不含题干、答案、算法、分数或标准答案解析。
4. 真实提交持久化后只解除该卷；所有未完成卷解除后才恢复内容帮助。保留历史“未取卷直接提交”的兼容行为，不把它称为独立表现证明。
5. 作答窗口与取卷、提交、AI 共用判据：`assessments.closed_at` 为硬关闭；前测所属课题已进入 posttest/closed 时拒绝。保留 running 时可补交前测的既有规则，不把 `pre_closed_at` 自动解释为关卷；也不静默把课题 `post_closed_at` 解释为后测硬关闭。后测等需卷级明确关闭。
6. 新增卷创建者的显式整卷关闭接口（教师或研究者角色，且必须为创建者）；旧两个 probe 关闭入口共用同一校验。关闭不可逆，首次时间保留；不删除已交答卷、未交不算完成、不得恢复同一份卷；重测需另发新卷。教师角色本身不赋予跨创建者关闭权限。本保证不扩展为已修复全部旧研究管理接口。
7. 本片不提供学生取消/清空首开/恢复旧卷的接口。关闭标签、刷新、离页、客户端取消不解除；要中止由创建者明确关闭整卷。逐生取消与审批工作流留待独立设计，不虚构已经支持。
8. 取卷和提交的最终许可与落库使用短事务；不持有数据库写锁等待外部模型。模型外发前再检查，回包/失败 fallback 前再检查；生图每个候选地址均检查。调用期间出现新的取卷记录，即使其已提交/关卷也丢弃在途内容。授权前已开始测评可证明零调用；已经发出的请求不能追溯撤回，不承诺数据库与远端网络原子性。
9. 测评不能遮蔽安全求助：先执行原有本地内容风险识别；明确高危请求获得固定安全支持与必要的风险事件，不调用模型，不要求先交卷，也不假称教师已收到通知。测评期间不写正常教学事件；风险事件不等同教学证据。本片不扩大风险正文采集范围。非测评旧聊天危机文案及旧风险计数口径未整体重构，仍属后续安全治理事项。

## 验收门槛

- 正常课堂聊天/生图确实到达隔离传输替身；历史 D1 回归保持。
- 各 kind、双角色、跨客户端、伪造 session/room/客户端状态、推送假完成、分页外老卷、撤回与多卷均有真实路由负例。
- 拒绝同时核对响应、模型函数调用、网络替身计数和正常教学日志无新增，不能仅凭 HTTP 状态或一个替身计数判断通过。
- 有效提交、本人教师关闭、未取卷、失败取卷、迟到前测、在途开启/关闭以及生图重试具有独立验证。
- 全部测试预导入隔离、合成学生、禁止外网和真实数据库。独立代理按架构安全、教育测量、测试可信度分项 0–4 诊断，不合计为教学效果得分。

## 明确边界

这不是防作弊系统：不能约束外部 AI、第二设备或教师线下帮助。旧身份验证仍为开发演示体系，不能据此宣称生产身份安全。前端提示、可信 AI 会话、新研究批次与取消审批未交付；研究卷计分与既有合法提交判断未重构，不能把“提交”推断为能力或教学效果。

整卷关闭不等于学生自主退出；本片未提供个别中止后恢复教学的机制，不能以全班停测或强迫交空卷替代无惩罚退出。真实启用前必须盘点历史已取卷未终结记录并由合法责任人处理，不自动补交、取消或追认历史记录已受 v1 保护。此为上线前待办，不访问真实库执行盘点。
