# M1a：可信课堂会话元数据合同

状态：本片实现与隔离验收；不是 M1 全部完成，未接前端和 AI。
对应主方案：`2026-10-11-pair-learning-review.md` 的 M1 首个小切片。

## 1. 边界先行

- 只支持 **一名学生与 AI 结对的课堂上下文**，`mode=student_ai`。不是两名真人协作，AI/IP 不充当第二名学生。
- 教师分配 `driver|navigator` 真人职责；`teacher_assigned_not_observed` 仅表示分配，不证明履职、贡献或能力。账号角色、真人职责、IP、支架政策保持分开。
- 不接旧聊天房间、不读取会话正文，不调用模型、不改变提示词、S0–S3、D1 渐退、历史研究条件或评价算法。
- `scope=task`；不生成单元画像、能力分数或教学效果结论。
- 前端、运行中服务、真实学生库、部署 `.env` 均不改变。新接口在下一次经授权的部署启动后才注册；本片不替用户启动真实采集。

## 2. 权威来源与缺失的历史事实

一个事务中校验：已认证教师 → 本人建立的班级 → 本人发布的具体 `push_id` → 本人已发布 exercise → 此次推送接收学生及当前班级成员 → 学生既有 `TaskAttempt` → 若有作品，其当前归属与语言一致。

尝试的 `task_id` 必须是 `exercise:{数据库题目ID}`。旧自由文本任务不自动迁移、不猜测对齐。没有作品的早期尝试可关联 `project_id=null`；已关联作品的尝试改绑或作品删除后，旧会话拒绝继续使用。尝试的客户端 `ai_condition` 不作为可信政策来源。

教师、学生每次读写均重新验证关系；陌生学生或非创建教师收到 404。所有者关系失效、撤回、研究关联或过期时拒绝。没有“只凭 teacher 角色读全校”的路径。

旧推送没有存当时的不可变题目版本。因此新建时只能冻结 **本次会话快照**：

| 字段 | 含义 |
|---|---|
| `task_snapshot_id` | 服务端生成的快照唯一编号 |
| `task_snapshot_hash` | 白名单内容规范 JSON 的 SHA-256，用于版本比对，不是防篡改签名 |
| `task_version_status` | 固定 `session_snapshot_only` |
| `original_push_version` | 固定 `null`；明确历史缺失，不回填猜测 |
| `created_at` | 本次捕获快照的服务端时间 |

快照白名单只有 `title/summary/statement/language/starter_code`，没有参考答案、提示全文、隐藏用例、学生代码或同伴信息。教师修改题目内容不会改变旧快照，新尝试可捕获新快照。旧任务撤回发布、删除或改变归属则停止使用，不能以冻结快照绕过当前授权。教师误把答案写进公开题干/起始代码仍属于内容审核问题，不声称白名单能自动识别。

## 3. 政策与研究条件不冒充已执行

响应固定包含：

```json
{
  "policy": {
    "contract_version": "pair-context/v1",
    "enforcement_status": "not_connected",
    "assigned_condition": null,
    "research_batch": null
  }
}
```

合同版本不是模型/提示词版本。`null` 不是“无 AI”实验组。拒绝客户端研究用途、研究组别、房间、政策、AI 条件、学生 ID 和留存期限等多余字段，不能靠伪造请求升级权限。

研究隔离采用保守拒绝：学生任意当前班级或历史冻结名单关联 `pretest/running/posttest` 研究时，普通会话接口拒绝创建和使用；即使从研究班转出，冻结名单仍兜底。活跃研究的班级列表损坏也明确拒绝，不悄悄视为普通教学。草稿、已关闭研究不在活跃阶段内；不会改写原研究记录、分组、退出状态或帮用户批准新的研究。

这不是独立测评 AI 禁用机制，真实 AI 请求还没有消费本合同。下一片必须接最终模型调用边界，不能仅在界面显示“受限”。

## 4. 最小接口

统一前缀 `/api/pair/sessions`，使用现有 Bearer 认证。

| 方法与路径 | 权限／行为 |
|---|---|
| `POST /`（实际路径不带尾斜杠） | 负责本班的教师创建；同一事务生成 session、任务快照和首轮；返回 201 |
| `GET /{id}` | 该学生或创建教师读取，返回冻结合同与轮次 |
| `POST /{id}/rounds` | 当前学生／创建教师开启下一轮；前轮必须已结束；返回 201 |
| `POST /{id}/rounds/{round_id}/close` | 幂等关闭本会话某轮，不接受其他会话轮 ID |
| `POST /{id}/close` | 幂等结束会话及未结束轮次，不提供重开或修改职责接口 |

创建请求：

```json
{
  "class_id": 1,
  "push_id": 1,
  "attempt_id": "att_SERVER_ID",
  "human_role": "driver",
  "request_id": "client-generated-retry-key",
  "purpose": "classroom"
}
```

下一轮只提交 `request_id`。请求键为 1–100 个英文字母、数字、下划线或连字符；标识整数严格拒绝布尔值及超出 SQLite 范围值。服务端生成 `pair_.../rnd_.../task_...` 唯一 ID。

同一教师＋同一创建键＋同一内容返回原会话；键相同而内容不同返回 409。一个 attempt 在仍留存的会话中只能绑定一次。下一轮重试返回原 round，序号由服务器分配；不同 session 的 R1 也有不同 round ID。关闭后不能新建轮次；永久撤回后任何会话业务读写均拒绝。幂等保证限于记录留存期，过期删除后不保留身份化幂等墓碑。

主要错误：401 未认证；403 角色/关系/同意失效；404 对无权者隐藏会话、找不到轮次或已被到期清理；409 来源变更、研究隔离、生命周期/幂等冲突；410 在清理与操作之间到期；422 请求不符合合同；503 部署未配置留存策略。数据库或迁移异常不伪装成功，事务回滚。

## 5. 原子性与存储

两张新表 `pair_sessions`、`pair_rounds`；单学生 ID 是可发现的独立列，不埋进 JSON。尝试外键删除级联到 session，再到 round。闭环不包含 AI 实际剂量、个人贡献或教学结果，这些不得从轮数推导。

- 使用已有启用外键的 SQLite 连接与 `BEGIN IMMEDIATE`；跨进程由数据库串行化写事务，不只依赖 Python 锁。
- 数据库约束：教师＋请求键唯一、attempt 唯一、session＋轮序唯一、session＋轮请求键唯一、每个 session 最多一轮未结束。
- 初始化使用 SAVEPOINT，添加表／索引失败整体回滚；重复初始化不改旧行。不对旧房间作任何推断迁移。
- 若创建首轮失败，session 与任务快照也回滚，不留半会话。关闭与新轮竞争只有两种合法事务顺序，最终不能存在关闭后的开放轮次。

## 6. 同意、留存、主体权利

沿用现有课堂同意作为技术门槛，并明确 `existing_classroom_consent_not_research`；它不证明新的研究、第三方流转、原文采集已获授权。初次同意时间冻结供解释，但每次仍验证当前授权。

`store.withdraw_consent` 在同一事务中永久撤销既有新会话、结束开放轮次。即使撤回与重新同意发生在同一秒，期间从未读取会话，也不能复活旧会话。撤回不冒充物理删除；本人导出仍是主体行使查阅权，不是恢复教学使用。

新增表同时进入个人数据数量、本人导出及删除清单，先删轮次再删父项；不会删除其他学生的独立资料。到期清理只影响新会话和轮次，不删旧 attempt/作品/证据。

创建默认关闭，部署者须按已批准的课堂政策**同时显式配置**：

- `PAIR_SESSION_RETENTION_SECONDS`：正整数，没有默认时长。
- `PAIR_SESSION_RETENTION_POLICY_ID`：非空政策版本标识，最长 120 字符。

本片只在合成测试中配置，不写部署 `.env`。填入这些值只是技术配置，不等同伦理批准、同意用途扩展或生产上线许可。

`expires_at` 是服务端访问截止时间。会话访问及个人查阅/导出触发过期物理清理；响应明确 `on_access_not_scheduled`。**没有后台定时清理任务，无人访问时数据可能仍在库中；不保证截止时刻物理销毁，不处理数据库 WAL 历史页、备份或已导出副本。** 真实启用前必须确认该清理模式符合批准政策；若要求定时销毁，另片增加维护机制后才启用。
