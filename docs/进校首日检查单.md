# 进校首日检查单

> 部署当天照单逐项打勾。分三段：**部署前（机房外）→ 开机验证 → 首节课现场观察**。
> 依据：三轮对抗式审计 + 端到端场景模拟 + 路线文档 §12「需要真实课堂验证」。

## A. 部署前（机房外做完）

- [ ] **A1 教师口令**：`server/.env` 设置 `JIEDUI_TEACHER_PASSWORD=<一句只有老师知道的话>`。
      **不设置 = 学生选「教师」页签就能拿到教师权限**（看全班预警、给自己开同意、拉标答卷）。
      设置后教师页签只认此口令，学生仍用演示密码。
- [ ] **A2 导出盐**：`JIEDUI_EXPORT_SALT` 已是 64 hex 正式值（2026-08-02 已生成）。
      **开始收真实数据后不可再换**（换盐 = 假名断链）。把值备份进老师保管的密码管理器。
- [ ] **A3 JWT 密钥**：`JIEDUI_JWT_SECRET` 已是正式值（2026-08-02 已生成）。轮换选课间做（会踢掉所有会话）。
- [ ] **A4 端口**：装机后先跑 `netsh interface ipv4 show excludedportrange protocol=tcp`，
      确认后端口（当前 **12210**）不在排除区间内。9000–9740 一带常被 Hyper-V 占用且**重启会漂移**，勿用。
- [ ] **A5 AI 密钥**：`AI_API_KEY` 有效且有余额；机房网络能通 `api.llm-token.cn`（校园网常封外网，先测）。
- [ ] **A6 启动**：先 `cd web && npm run build` 出一次产物，之后**双击根目录的 `启动平台.ps1`** ——
      单进程同端口伺服 API 与前端（脚本会自查端口排除区间、未设教师口令会红字提醒）。
      不需要反向代理，不需要第二个服务。
- [ ] **A7 门禁绿**：`pytest`（当前 99 passed）与 `npm run build` 三段全过再带出门。

- [ ] **A6 观察件打印**：《观察表与评分金标准_定稿》的 §A0（教师一页卡，塑封挂脖）、
      §A2（sweep 表，A4 横向）、§A3（focus 表，第二观察者用）。**§A11 认证先行**：
      观察员未通过上岗测试（κ≥0.75）前，其记录只作练习不入库。
- [ ] **A7 同意书打印**：`docs/合规/知情同意书_监护人版_模板.md`（【待填】补齐后方可印发）；
      收回后按 §三 勾选分流：仅第一勾进研究分析集。

## B. 开机验证（机房内，上课前 20 分钟）

- [ ] **B1 教师口令生效**：教师页签用演示密码 123456 登录 → 必须**失败**；用口令 → 成功。
- [ ] **B2 学生端断网可用**：拔掉外网，学生机进 IDE 跑一段海龟绘图 → 能画（Pyodide 已本地化）。
- [ ] **B3 Pyodide 首载掐表**：40 台首次同时进 IDE，掐第一台到最后一台可运行的时间。
      **> 60 秒 → 下一步是把 `web/public/pyodide/` 随机房镜像预装，不是优化前端。**
- [ ] **B4 同意书链路**：学生端点「申请开通」→ 屏幕出现「已通知老师」；教师端能看到待核验条目；
      教师在课题页点**批量开通** → 学生端刷新后 AI 可用。
      **这是唯一「平台在这个班完全不可用」的流程风险，必须现场走通。**
- [ ] **B5 AI 链路**：任一学生机发一条真实提问 → 有回复（`source` 非 fallback）。

## C. 首节课现场观察（路线文档 §12 的五个未决问题，观察而非提问）

- [ ] **C1** 学生在 IDE 里**没报错**但想问 AI 时怎么做？（若频繁跳回结对页 → 需要在 IDE 补轻量入口）
- [ ] **C2** 里程碑 toast 弹出时学生是否下意识去点关（若是 → 改为链条上留记号，不弹）
- [ ] **C3** 「小狐/小枭」形象是否引发「被当小孩哄」的排斥表达（初二初三峰值敏感；配合 P1-Gate 问卷题 1）
- [ ] **C4** 休息提醒（连续 40 分钟）是否被当成管束
- [ ] **C5** 教师会不会主动去点「课堂监看」——不点的话它就白做了，问一句原因
